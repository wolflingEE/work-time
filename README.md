# Work Time

Free offline working hours tracker for Android. Track shifts, earnings and expenses by work site, export Excel reports and keep file backups.

- [Official website](https://wolflingee.github.io/work-time/)
- [Download the signed APK](https://github.com/wolflingEE/work-time/releases/latest/download/work-time.apk)
- [Release history and SHA-256 checksums](https://github.com/wolflingEE/work-time/releases)

Available in English, Eesti, Русский and Українська. Requires Android 10 or later.

This repository hosts the public website, documentation and release downloads. The Android project is maintained separately.
